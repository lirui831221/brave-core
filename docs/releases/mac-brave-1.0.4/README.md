## 1.0.4 的缓存迁移

旧 DAT 继续提供保护，新规则与资源在独立层中校验，成功后启用。坏输入保留有效旧保护；
不把部分本地规则保存成完整 DAT，也不让晚到旧 DAT 覆盖完整重建结果。
冷启动输入失败时，仍为旧引擎补齐可用脚本资源。

完整源规则未重建前保留旧规则是一项兼容措施：全部规则撤销、订阅删除及旧源退役语义尚未完成审计。
官方组件目录仍受 HTTP 403 阻塞，不能写成完整在线迁移已通过。

本版 41 项相关自动化测试通过，包括 14 项迁移、9 项既有外观规则合并、10 项资源与启动、8 项订阅测试。
运行验证有 9 个候选场景和 2 个基线对照。YouTube 观察 644.55 秒，播放采样跨度 600.6 秒，
涉及 4 个不同视频、6 次进入，1080p、24/25 fps、AV1/Opus。暂停恢复、全屏通过；
本轮鼠标拖动进度和 30 分钟持续播放未测试，采样有 0 至 13 丢帧，不宣称零丢帧。

## 安装、更新与信任边界

使用 macOS 正常解压、签名和 Gatekeeper 检查。先退出旧应用并保存可恢复副本，再由用户确认安装。
不要移除隔离属性、关闭 Gatekeeper、关闭沙盒或忽略证书错误。
该应用仍与官方版共享 bundle ID；并行安装、钥匙串和应用身份迁移需另行规划。

从仓库根目录检查并下载此测试版，输出目录须尚不存在：

```sh
python3 tools/mac_local_update/update.py --include-prereleases --prepare \
  --tag mac-brave-1.0.4 --output /tmp/mac-brave-1.0.4-download-01
```

该命令仅检查和准备，不安装。安装流程及回退见 [更新工具说明](../../../tools/mac_local_update/README.md)。
默认只检查正式版，测试预发布必须显式加入 `--include-prereleases`。
已安装 1.0.4 可以下载同版本复验，但安装器拒绝相同或更旧版本；真实新版本升级安装仍未验收。

- SHA256、GitHub 资产摘要：文件一致性，不能独立证明发布者身份。
- 应用签名完整性：验证签名覆盖内容没有变化；发布者身份须另外核对 Team ID。
- 公证及 stapled ticket：本产物已完成；Gatekeeper 本机评估通过。
- Chromium 运行时沙盒：单独检查；以上任一通过不代表所有安全浏览服务可用。
- 部分嵌套更新组件保留其上游合法签名，外层发布者为 `7VG9U2TN4G`。

`package_candidate.py` 是生成 ad-hoc 本地候选的工具，不能单独复现本次正式签名与公证。
正式发布另需合法 Developer ID 证书、嵌套组件签名、Apple 公证及票据验证；本仓库不包含私钥或认证材料。
为保留已测试且已公证的原始字节，本包中的 `BraveLocalBuildStatus` 仍为 `unreleased-candidate`。
GitHub 上将其标为测试预发布，并未宣称为稳定版。
