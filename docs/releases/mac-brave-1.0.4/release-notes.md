# mac brave 1.0.4

这是基于 Brave 开源代码的 **macOS Apple Silicon（arm64）定制测试预发布版**，不属于 Brave 官方发行版。
本次发布与本机已安装验收的 1.0.4 使用同一份二进制，没有重新打包或改变签名。

## 下载与安装

- 安装包：`mac-brave-1.0.4-macos-arm64.zip`（300,849,296 字节，约 287 MiB）。
- 定制发行号：`mac-brave-1.0.4`；内部 Brave：`1.98.0`；Chromium：`155.0.8059.16`。
- Developer ID 签名、公证票据及本机 Gatekeeper 检查：**通过**。预期发布者 Team ID：`7VG9U2TN4G`。
- 下载后使用 macOS 正常解压和安装流程。先退出现有浏览器并保留旧应用备份，再安装。遇到系统拒绝时应核验文件及签名，不应关闭 Gatekeeper 或移除隔离属性。
- 本版仍使用 `com.brave.Browser`，独立应用身份迁移尚未完成；不要把它与官方同名应用混装。数据产品目录标记为 `BraveLocalBuild/Brave-Browser`。

安装包 SHA256：

```text

```

## 本次包含的改动

- 保留有效旧 Shields DAT 缓存；新规则和脚本资源独立校验成功后再启用。失败继续保留旧保护，不依赖删除缓存。
- 不让不完整的本地规则集合覆盖完整 DAT，避免后续启动重复漏载；晚到的旧缓存也不能覆盖已完成的新引擎。
- 保留前序 YouTube 规则、脚本资源、首屏加载时序和站内跳转修复，以及订阅失败保留缓存、Dark Reader 下载修复。
- 保留附加服务精简和自有 GitHub 检查、下载校验、确认后安装工具；不宣称完整后台自动升级。

## 已知限制

- **尚未验收“任何场景都没有 YouTube 广告”**。有限样本未见片头广告不等于所有广告都被阻止；本版也未完成 30 分钟持续播放验收。
- **失败／受阻**：安全浏览及部分 Brave 组件服务仍返回 HTTP 403。公开过滤规则可用不能代表这些服务已恢复，保护能力不能声明与官方发行版等效。
- **未测试**：自然到期刷新、真实扩展版本升级、通过新 Release 完成真实程序升级安装。
- **未完成审计**：完整源规则未重建前，部分旧缓存规则继续兼容保留；全部旧规则撤销语义尚未逐项验证。
- 未宣称服务精简带来安装包或内存显著减少。未完成独立应用标识、钥匙串迁移。
